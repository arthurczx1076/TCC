# The Vitality Clinic

Site institucional desenvolvido para a **The Vitality Clinic**, uma clínica voltada à promoção da saúde, qualidade de vida e bem-estar, oferecendo diferentes especialidades e atendimentos em um único espaço.

O projeto tem como objetivo apresentar a clínica, seus serviços e especialidades, proporcionando aos visitantes uma experiência de navegação moderna, intuitiva e acessível.

---

## Sobre o Projeto

O site foi desenvolvido para apresentar os serviços da clínica, destacando suas áreas de atuação, estrutura e canais de atendimento.

A plataforma reúne informações sobre quatro especialidades principais:

- **Nutrição:** acompanhamento nutricional e orientação alimentar.
- **Fisioterapia:** cuidados voltados à recuperação e manutenção da saúde física.
- **Cardiologia:** atenção à saúde cardiovascular.
- **Massoterapia:** tratamentos voltados ao relaxamento e bem-estar.

A proposta é oferecer uma presença digital profissional, transmitindo confiança, acolhimento e credibilidade aos visitantes.

## Tecnologias Utilizadas

O desenvolvimento foi realizado utilizando as seguintes tecnologias:

| Tecnologia | Descrição |
|---|---|
| HTML5 | Estruturação e organização do conteúdo do site. |
| CSS3 | Estilização, identidade visual, layouts e responsividade. |
| JavaScript | Implementação de interações e funcionalidades dinâmicas. |

Também foram utilizados recursos externos, como Google Fonts, para composição da identidade visual e tipografia.

## Funcionalidades e Recursos

O projeto apresenta os seguintes recursos:

- Página institucional da clínica.
- Menu de navegação entre as seções.
- Apresentação das especialidades disponíveis.
- Seção dedicada aos serviços de saúde.
- Utilização de imagens para apresentação da clínica.
- Identidade visual própria, com logotipo personalizado.
- Navegação entre diferentes áreas do site.
- Atalho para agendamento de consultas.

### Descrição dos Arquivos

**assets/**

Diretório responsável por armazenar os recursos visuais utilizados no site, incluindo imagens das especialidades, fotografias da clínica e logotipo institucional.

**index.html**

Arquivo principal do projeto, responsável pela estruturação do conteúdo, organização das seções e elementos da página.

**style.css**

Arquivo responsável pela identidade visual do site, incluindo cores, fontes, espaçamentos, posicionamento dos elementos, layouts e adaptação da interface.

**script.js**

Arquivo responsável pelas funcionalidades e interações implementadas em JavaScript, proporcionando maior dinamismo à navegação.

**README.md**

Arquivo de documentação que apresenta o projeto, suas tecnologias, organização e instruções de execução.

## Como Executar o Projeto

Para visualizar o site em ambiente local:

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Acesse a pasta do projeto:

```bash
cd The-Vitality-Clinic
```

3. Abra a pasta no Visual Studio Code.

4. Execute o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server para facilitar a visualização durante o desenvolvimento.
